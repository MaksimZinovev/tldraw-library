# Upstream source

The symbol renderer is Ferroprint (bjarneo/ferroprint), loaded at build time from the local checkout `../ferroprint` (override with FERROPRINT_DIR). Recorded upstream commit: e501013 (2026-10-08), "Let a project use its own logo in the title block".

Ferroprint ships no LICENSE file at that commit, so no upstream source is committed here — only generated SVGs and clipboard content. If this repo is ever published, clear the upstream licensing question first.
